# AI Lead Generation & Outreach Automation using Clay AI

## Project Overview

This project demonstrates an AI-powered sales automation workflow built using Clay AI.

The workflow enriches company information, identifies decision-makers, generates personalized outreach messages, and scores potential leads using AI.

---

## Features

- Company Research
- Website Enrichment
- Industry Classification
- Employee Count Analysis
- CEO Identification
- LinkedIn Company URL
- Company Description
- Business Challenge Detection
- AI Solution Suggestions
- AI Benefit Summary
- Personalized Outreach Email
- LinkedIn Connection Request
- Follow-up Email
- AI Lead Scoring
